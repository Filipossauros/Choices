A escala de valor é a interpolação monótona-cúbica (PCHIP) que passa por todos os pontos derivados — suave, sem oscilações. Âncoras: Neutro = 0, Bom = 100. Desempenhos contínuos são lidos diretamente desta curva.

✅ P1·S4 PCHIP PRESERVADOA função matemática (gráfico recharts LineChart + interpolação PCHIP) não sofre qualquer alteração. O componente ScaleFormula em Scales.tsx permanece intacto. Os pontos azuis são os nós derivados pelo LP; a curva azul é a interpolação monótona-cúbica (engine/interpolation.ts:sampleCurve). As linhas de referência Neutro/Bom são inalteradas. O Modo Guiado apenas muda o input — o output é idêntico.
